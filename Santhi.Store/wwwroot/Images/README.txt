Santhi.Store - 100 demo product images

Contains 100 individual JPG image files, cropped from a generated product-image sheet.
These are illustrative demo images. Product packaging, brand marks, and labels may be
AI-generated/inaccurate; do not treat them as official brand product photography.

To use in an ASP.NET Core MVC project:
1. Extract this ZIP.
2. Copy the 100 JPG files into your project's wwwroot/images folder.
3. In the product Create form, upload one JPG per product.
4. The application should save the generated image path in the ImageUrl column.

The files are JPG images and can be used to test the upload workflow.
